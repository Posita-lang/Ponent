A `as` (safe cast) between incompatible types: a reference type requires an explicit dereference or an unsafe `as!` bitcast; safe casts are only allowed between numeric and boolean types; casting a reference to an integer is not yet supported; an unsafe cast requires compatible types (numeric↔numeric, ref↔ptr, ptr↔ptr).

Fix: dereference the value first (`*expr as TargetType`), use `as!` for an explicit bitcast, or cast between compatible types.
