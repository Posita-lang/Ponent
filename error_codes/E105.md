Every alternative of an or-pattern (`pattern1 | pattern2`) must bind the SAME set of variables (SYNTAX.md: "Both patterns must bind the same set of variables with compatible types").  A variable bound in one alternative but not another cannot be given a consistent type in the branch body (OCaml reports this as `Orpat_vars`).

Fix: bind the same variables in every alternative, or use `_` for alternatives that should not bind.
