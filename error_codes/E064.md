The right-hand side of a GADT `when` constraint cannot reference another type parameter of the SAME enum.

For example, the following is invalid because `U` is a type parameter of `Bad`:
  type Bad<T, U> = enum { Mk(T) when T == U }

A mutual constraint (`when T == U and U == T`) would register a refinement cycle (A → B, B → A) that type resolution would chase until the chain-depth limit.

Fix: use a concrete type on the right-hand side, or an `exists` variable scoped to the variant (the witness stays opaque).
