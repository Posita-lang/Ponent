Variables in Ponent are immutable by default (SYNTAX.md §Variable Declaration). Reassigning a variable declared with `set x = ...` (or a `let` binding) is rejected — `x = value` and `x += value` both require the binding to be mutable. Declare the variable with `set mut x = ...` to allow reassignment. Function and method parameters are mutable rebindable slots (the grammar has no parameter-level `mut`), so `ls = tl` walks type-check. Field and index writes through a `&mut T` or raw-pointer root are allowed via implicit deref; `*r = v` is governed by the reference's own type-level mutability and the borrow check, not by the binding `r`.
