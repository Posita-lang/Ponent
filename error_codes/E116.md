The Polonius drop rule (`evaluate_drop_errors`): a dropped value whose loan is still live at the drop point — the borrow outlives the value (rustc E0505).  The drop destroys the value while a borrow of it is still live, so the borrow would dangle.

Fix: end the borrow's scope (its borrow variable's last use) before the value is dropped, or reorder the code so the drop happens after the borrow is no longer needed.
