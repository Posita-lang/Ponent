An isolate block must not access or mutate external mutable state
(SYNTAX.md §Task Isolation — "does not access any external mutable
state").  Reading or writing a mutable global, or assigning to a
captured outer mutable variable, inside an isolate block is rejected.

Declare the variable inside the block if it is meant to be internal
state, or restructure the code so the isolate block only touches its
own state.
