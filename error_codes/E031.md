The kind of a type does not match the expected kind.

This occurs when a type inference variable has a kind constraint (e.g. Integer,
Bool, Float) that conflicts with the resolved concrete type.  For example, using
a string variable where an integer is expected.

Example:
  set j = "hello";
  set i = j + 1;  // error: expected integer type, found &Str

Fix: ensure the value has the correct type kind for the operation.
