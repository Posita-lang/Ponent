A comptime block or comptime function failed during evaluation.

The evaluator's error message is attached and is the specific cause.
Common causes include:
- A comptime block containing an item declaration (`type`, `def`, `impl`,
  `trait`, ...) — comptime blocks only allow expressions, variable
  definitions, and assignments.  Use a `generate` block for
  declaration-level code generation.
- A comptime function or block referencing a value that is not computable
  at compile time.
Fix the comptime code so it evaluates successfully.
