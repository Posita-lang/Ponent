The Polonius fact extraction encodes each CFG point as an integer (block << 36 | stmt << 16 | expr).  A function with more than 1,048,575 CFG blocks, more than 1,048,575 statements in a single block, or more than 65,535 expressions in a single statement exceeds this internal encoding capacity — an internal compiler limitation, not a program error.

Fix: split the function into smaller functions, or report the issue if the function is not unusually large.
